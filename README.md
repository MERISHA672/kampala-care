# KampalaCare 🇺🇬

KampalaCare is a modern service discovery and booking platform designed to help people find trusted local service providers in Uganda.

The platform allows users to explore different services, compare providers, check ratings, and make service booking requests from one place.

## 📌 Project Overview

Finding reliable service providers can sometimes be difficult, especially when you don't know who to trust or how much a service may cost.

KampalaCare was created as a simple digital solution that connects customers with local professionals such as cleaners, plumbers, electricians and beauty specialists.

The project focuses on creating a clean, responsive and easy-to-use user experience.

## ✨ Features

- 🔎 Service search
- 🗂️ Service category filtering
- 👨‍🔧 Provider profiles
- ⭐ Provider ratings and reviews
- 📅 Service booking form
- ❤️ Favorite services
- 🔐 Login interface
- 🌙 Dark mode
- 🔔 Toast notifications
- 💾 LocalStorage support
- 📱 Responsive design
- 🖥️ Desktop and mobile layouts
- 🎨 Modern user interface

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts and responsive design
- **JavaScript** – Interactivity and application logic
- **LocalStorage** – Saving user preferences and booking information
